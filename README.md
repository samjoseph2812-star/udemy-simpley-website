Udemy Clone Website – README Description
📚 Project Overview

This project is a Udemy Clone Website created using HTML and CSS. The website is designed to replicate the basic layout and user interface of the popular online learning platform Udemy.
The main purpose of this project is to improve frontend web development skills by building a responsive and modern educational website interface.

The website includes multiple sections such as:

Navigation Bar
Hero Section
Course Categories
Featured Courses
Student Reviews
Footer Section

This project focuses mainly on website structure, layout design, and responsive styling using pure HTML and CSS without using JavaScript or frameworks.

🚀 Features
✅ Responsive Design

The website is designed to work properly on desktop, tablet, and mobile devices using CSS responsive techniques.

✅ Modern User Interface

Clean and attractive UI inspired by the real Udemy platform.

✅ Course Cards

Displays different course cards with:

Course title
Instructor name
Ratings
Price details
✅ Navigation Menu

Simple and easy-to-use navigation bar for better user experience.

✅ Hover Effects

Interactive hover effects added using CSS to improve visual appearance.

✅ Footer Section

Includes useful links and social media sections.
